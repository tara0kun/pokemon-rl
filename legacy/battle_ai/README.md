# バトルAI（汎用ポケモンAI 第4層）

## 目標
技選択・交代判断をRLで学習する汎用バトルAI。
GBA/DS作品間で構造を共有、再学習で対応。

## アーキテクチャ
- **入力**: 自分(種族,Lv,HP%,PP残,4技ID,タイプ) + 敵(種族,Lv,HP%,タイプ)
- **出力**: 行動(技1/技2/技3/技4/交代slot1-5)  = 9アクション
- **報酬**: 敵HP減少(+), 自HP減少(-), 勝利(+大), 敗北(-大)
- **学習**: PPO (stable-baselines3)

## ファイル構成
- `battle_env.py` — バトル専用Gymnasium環境
- `battle_sim.py` — Gen3ダメージ計算シミュレータ
- `train_battle.py` — 学習スクリプト
- `type_chart.py` — タイプ相性テーブル（Gen3）

## 段階
1. ダメージ計算シミュレータ（オフライン）
2. バトル環境（シミュレータベース）
3. RL学習（PPO）
4. 実機連携（mGBAバトル中に行動決定）
