## 重大発見 2: VAR_PETALBURG_CITY_STATE は coord trigger

```
PetalburgCity coord_events:
  (8, 10/11/12/13) PetalburgCity_EventScript_ShowGymToPlayerN
    var: VAR_PETALBURG_CITY_STATE, var_value: '0'
  (4, 10/11/12/13) PetalburgCity_EventScript_ScottN
    var: VAR_SCOTT_PETALBURG_ENCOUNTER, var_value: '0'
```

= **agent が y=10-13 row の x=8 column を踏むたびに「ジム説明 + rookie trainer」
dialog auto-trigger**。 VAR が advance するまで永久反復。 VAR を advance させるのは
**Petalburg Gym 内 Norman/Wally 会話イベント** のみ。

私が deploy した 12+ patch は全て **「(8,13) で stuck → dialog A 連打 → 同 tile 戻り」
の cycle を細部最適化** しただけで、 真の解決には到達不能だった。

## 教訓 (memory 化)

1. **canon `coord_events` を チェック必須**: maptools のスクリプト trigger を真っ先に
   確認する。 chronic stuck 時は walkable / NPC より先に coord_events で VAR check。
2. **VAR / FLAG ベースのストーリ進行を canon で把握**: pokeemerald 各 script の
   var_value / flag を辿ると、 hard wall がどの event 完了で開くか明確。
3. **party_count の RAM read race を信用しすぎない**: SaveBlock1 ptr が 一瞬
   invalid な瞬間に read 値が 1 や 0 になる。 `stable_read` で 2-3 連続一致を確認。
