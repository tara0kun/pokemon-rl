## 今日ハマった罠(次回のため)

- **`time.sleep=None` clobber**: inline script で `time.sleep=... if ... else time.sleep(x)` の類を書くと `time.sleep` に None が代入され次の tap で crash。本セッションで ~5 回踏んだ。**time.sleep へ代入しない。** 長い drive はファイルに書く。
- **メニュー開き snapshot**: `at_norman_chesto.ss1` を START メニューが開いた状態で保存 → 復元後の nav の Down/A がメニュー内に着弾し player が動かず OPTIONS を開く事故。**savestate は clean overworld から保存する。**
- **read_state が遅い(~2.5s)**: socket が empty reply を頻発し read_state の retry で膨らむ。nav では `SaveBlock1 ptr(0x03005D8C)+x/y(0x00/0x02)` を直接 read すれば ~0.02s。fast read は EmulatorError を retry で握る。
- **held item の RAM decode**: personality%24 で substructure 並びを引き、Growth 先頭 u32 を `^(otid^pv)` して `(w0>>16)` が held_item id(Chesto=134)。party_dump に無いので scratch で実測。
- **TM 互換性を思い込まない**: Sceptile は Bulk Up(TM08)を**覚えられない**(NOT ABLE)。party 画面の ABLE/NOT ABLE を確認せず A を押すと別 mon(Slakoth)に誤習得して TM を浪費する。restore で巻き戻せた。
