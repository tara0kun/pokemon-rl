## 教訓(横断)
- **goal を追加したら directed_goal prefix / map-gate / flag-gate を必ず確認**(explore hijack・map漏れ・flicker で繰り返し stall した)
- **latch は過去イベント専用**。未来イベントの `not X` gate は raw flag
- **run() は未 unittest** = NameError 系は live まで露呈しない。編集後は短時間 live smoke check
- **`&` 起動は Bash 終了で SIGHUP 死** → run_in_background を使う
- **SakanaAI は quiescent tree で**(並行 production commit が gate path-violation を招く)
