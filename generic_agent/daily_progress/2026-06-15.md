## 設計レベルの主な変更

### A. PWhiddy v2 reward port (`reward_state.py`)
- `event_flag_delta × 4`、 `heal × 10`、 `badge × 10`
- `record_same_map_penalty` を escalating tier (-0.5 → -1 → -2) に強化
- recent-map decay 0.05 → **0.5 (10×)**
- `RECENT_MAP_PENALTY_PER_VISIT = 30` を score_direction に注入

### B. 2,400 bit event flag observation (`brain_cnn.py`)
- `STATE_DIM`: 28 → **2,464**
- 全 event flag を ベクトル化、 8-bit badges、 recent_actions one-hot、 opponent level slot
- `MultiModalBrainCNN` に 4-frame channel-stack の 1×1 reduce conv 追加

### C. NPC RAM reader (`state.py`)
- `gObjectEvents` (0x02037350) から 16 sprites の (x, y, graphics_id) を読む
- heuristic は壁か NPC かを区別、 NPC 隣接方向を navigate 候補から除外

### D. Claude Plays Pokemon-style hybrid LLM advisor (`llm_advisor.py` + `pokemon_emerald_knowledge.py`)
- Haiku 4.5 を **dialog / menu / new_map / same_map_streak ≥ 200 / pos_stuck ≥ 8** で sparse 召喚
- `pokemon_emerald_knowledge.py` (3,687 chars) を system prompt として注入 (CLAUDE.md の hardcode 禁則は prompt OK)
- cache_control で prompt cache 効かせて 1 call ≈ $0.0017

### E. Multi-hop BFS + novelty drive (`path_memory.py` + `goals.py`)
- `find_path_to_map`: 既知 transition graph を BFS、 2-3 hop 先の goal map を計画
- `find_nearest_unexplored_map`: recent 6 map を avoid して未訪問領域に向かう
- `goals.py` の `get_starter` target = (1,0) Brendan house → **(1,4) Birch's lab** に修正 (致命的 typo)

### F. GPU 移行 (`tools/train_imitation.py` + `tools/continuous_train.py`)
- PyTorch CPU → **cu128 (RTX 5060 7GB VRAM)**
- 1 epoch: 497 秒 → **38 秒 (13× faster)**
- `--max-samples N` を **末尾 N rows** に変更、 古い stuck demos を訓練から除外
- num_workers = 0 (Windows DataLoader hang 回避)

### G. autonomous_monitor.py に 30 分毎 self_check 統合
- `self_check_analyze`: 直近 8 iter scores + milestones + button_frac から異常検知
- Issues: `CNN_degraded` (5+ iters < 25)、 `CNN_val_collapse` (max_button_frac >= 0.99)
- Actions: filter rotation、 hyperparam tune ヒント
- `self_check.jsonl` に永続 log、 Claude session と完全独立 (subprocess)

### H. SB3 PPO env (`env_ppo.py` + `tools/train_ppo.py`)
- Gymnasium `MultiInputPolicy` + `VecNormalize`
- 30K timesteps 検証完了: `explained_variance` 0.11、 active gradient (clip_fraction ~0.27)
- BC weight warm-start adapter 計画 (key namespace mismatch のため未実装)
