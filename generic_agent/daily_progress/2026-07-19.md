## 午後の追加成果 (field_heal 深掘り + battle + gym 到達)

ガントレット突破後、descent を live で走らせて出た問題を実測で根治:

- **field_heal 真因 ×2 を実測特定・根治(commit 6871aebf0)**。① START menu は overworld
  callback の overlay で `game_cb2` を変えない(live 確認: Start 1回で menu 出るのに cb2 不変)
  → 旧「cb2==overworld なら Start」guard が menu を開閉トグルし 40 step 空振り。cb2 で
  menu-open を判別できないので **vision-driven + toggle-breaker** に再設計。同一バグを
  hm_teach にも発見・修正(誤コメント「cb2 flips instantly」訂正)。② Super Potion は ITEMS
  pocket の 5番目なのに VLM が先頭の別 item を「Super Potion」と幻覚 →「効果がない」ループ。
  全 party・全 item を RAM 実測して確定 → **一意の数量 x6 で選ばせる** prompt に修正。
  **live: Sceptile 39→134 を 8 step で満タン回復**。memory `vlm-menu-subtask-gotchas` に保存。
- **double-battle latch(commit 80ff69b08)**。Jagged Pass の Sceptile L41 vs Shroomish+
  Magnemite L21 double が **25 分 command menu で stuck**。真因は battle_flags の 0x1(double)
  bit が move-select 中に 0 へ flicker(0x8 trainer bit は既に latch 済だが 0x1 は未 latch)
  → double 分岐を外し single move_select が double target を処理できず command menu 帰還ループ。
  **trainer-latch と同型の double-latch** を追加(battle 中に 0x1 を一度観測したら終了まで維持)。
  詰まった battle は手動 A 連打で勝利させ unblock。
- **field_heal dialog-preclear + 閾値 0.50(commit 7a4a5d71b)**。NPC dialog が開いた瞬間に
  発火すると Start opener が効かず VLM が SAVE menu まで迷走 → opener 前に B×2 で dialog を
  pre-clear。Maxie 用の 0.80 閾値は突破済で obsolete、descent の chip damage で churn する
  ため 0.50 に下げた(Flannery 前は PC が満タン回復)。180 green。
