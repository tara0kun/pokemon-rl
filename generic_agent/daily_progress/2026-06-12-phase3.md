## RAM 拡張

`state.py` に gPlayerParty[0] 読込追加 (Emerald USA 0x020244EC + struct
Pokemon offsets):
- party0_level (offset 0x54)
- party0_hp (offset 0x56)
- party0_max_hp (offset 0x58)
- `hp_frac` property = current/max

これにより model は 「starter の HP 割合」 を判断材料にできる。 RAM
**書込なし**、 SaveState load なし、 ハードコード座標なし のルール準拠。

## Demonstration 3 経路

### 経路 1: Sonnet API (1831 demos)
v51b で auto_loop --dataset を Sonnet で 3000 turn 走行。 Sonnet が Brain
として screenshot 見て button 決定、 demos に記録。 cost $1.50。

### 経路 2: Claude conversation manual (200 demos)
新規 `claude_play.py` で snapshot + step CLI 提供。 私 (Claude Code
セッション) が screenshot を Read tool で見て、 button を Bash で
送信。 寝室 → 1F → Littleroot 街 → Lab 接近 → Route 101 進入 の
正解 path を hand-crafted demo として記録。 API cost $0。

### 経路 3: Claude heuristic (3800 demos)
新規 `claude_heuristic.py` で 私の Pokemon 知識を Python rule に
embedded:
- trainer-vs-wild battle dispatch
- last_action=='A' 厳格 dialog 検出
- 8-turn 同 pos で Up/Right/Down/Left rotation escape
- path_memory + onward-score での known exit navigation
- BFS prefer="farthest" on fresh maps
- North bias direction priority

自律走行で 1500-3000 turn × 複数セッション。 cost $0。
