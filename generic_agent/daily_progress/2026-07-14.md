## 主要成果

### 1. live map-collision（本セッション最大の技術成果）
- Mauville Gym の電気バリアは**メタタイルのスイッチで開閉**し、static map.bin には反映されない → BFS が Wattson へ NO PATH で解けなかった。
- **`gBackupMapLayout`(0x03005DC0 IWRAM → sBackupMapData 0x02032318 EWRAM)** から現在のメタタイル collision を読み、BFS に反映（`state.read_live_walkable_overrides` + `bfs_to_tile(extra_walkable=)`）。research agent が state.py の既知シンボル5個と cross-validate して最大確度で RAM アドレス特定。static BFS 失敗時のみ発火（puzzle マップ限定）。
- collision bit: MAPGRID_COLLISION_MASK 0x0C00、grid_index=(x+7)+(y+7)*padded_width。

### 2. gym パズル攻略の複合修正
- **phantom-battle 修正**: gym の黄色い床＋バリアを vision が battle_menu と誤検出（RAM in_battle=0/10）→ agent が FIGHT メニューに 3000+ turn 張り付き。**RAM で最近戦闘が確認された時のみ vision battle_menu を信用**（ram_battle_recent、12 turn window）。
- **keep-in-gym frontier explore（escape より前）**: goal マップで target 不到達なら退出せず未訪問タイルを探索してスイッチを踏む。frontier 枯渇時は **pseudo-random re-walk**。
- **heal 修正**: gym の6トレーナーで Grovyle 消耗 → Mauville PC 回復。nurse はカウンター奥で walkable neighbor なし → **target_pos を counter(7,3) にして (7,4) から Up+A（MB_COUNTER 越し）**。さらに **PC マップ自体を heal goal の cur-set に追加**（PC 入場で goal 脱落 → reach_mauville が追い出す bounce を解消）。

### 3. 再解問題と tile_map クリア（運用）
- 回復後の gym 再入場でパズルがリセット + tile_map が全訪問済で汚染 → frontier 枯渇 + 隣接 NPC で袋小路（5タイル）に閉じ込め。
- **gym(10,0) の tile_map + path_memory を手動クリア** → 未探索状態に戻り frontier 探索再開 → バリア再突破 → **再入場時はトレーナー撃破済で Grovyle full HP のまま Wattson 到達 → 撃破 → Badge 3**。
- ⚠ **follow-up**: puzzle-gym 再入場時の tile_map 自動クリアをコード化すべき（今回は手動）。
