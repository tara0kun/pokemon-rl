## §22 Cycle 14: BFS hint injection + path_memory blocked filter + HARD PRIORITY prompt + cache fast eviction

### 分析手順 (multi-agent workflow)

v33 が 18 unique pos で停止した root cause を 3-finder workflow で分析:

| Finder | 角度 | 結果 |
|--------|-----|------|
| A | tile_map 解析 (Route 101 構造) | ❌ 反証: (10,0)/(11,0) は lazy-creation artifact、 東 corridor 実際は dead end |
| B | cache 解析 (key collision 仮説) | ❌ 反証: Route 101 内では fhash↔pos 1:1、 pos-keying は no-op |
| **C** | prompt + path_memory 解析 | **✓ 確定**: navigate prompt に BFS direction が無く、 path_memory が stateless で first char "U" を再生 |

### Root cause (確定)
v33 の 281 navigate call 全てが `path_memory.summary_for("0-16")` 経由で "UUURUUUD → 0-9" を見て、 prompt 指示 「first character of that sequence」 に従い **常に Up を返答**。 Route 101 北壁で Up は blocked → ping-pong 永続。 `tile_map.bfs_frontier_direction()` は計算されていたが force_recovery rule branch 内のみで、 **Brain prompt に流れていなかった**。
