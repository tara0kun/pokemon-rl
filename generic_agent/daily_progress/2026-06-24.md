## iter 30 update (20:15 時点 = grass nav 100 step encs=0 + Haley blocked)

### 真の root cause 第 6 段 発見

`canon walkable()` 関数:
```python
def walkable(self, x: int, y: int) -> bool:
    return self.collision[y][x] == 0
```
= **collision == 0** (open ground) のみ True、 grass tile (collision != 0) 除外

しかし Route 104 collision に grass marker なし (unique values = [0, 1] のみ)。
grass tile は **metatile_attribute** (canon JSON に含まれない) で識別。

= **agent はどこに grass があるか canon から判別不可** + heur BFS が grass 確率回避
不明 = wild encounter 0/100 step。
