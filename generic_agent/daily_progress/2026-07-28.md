## Petalburg Gym = 縦積み warp puzzle（map (8,1), 9×112）
- **1 マップ内**に部屋が縦に積まれ、部屋間は **behavior-0 の warp タイル**（door）で接続。
  door は「その部屋の trainer を撃破」で script 側が開通。map warp events は
  `map_data.get(8,1).warps` に全部入っている（ground truth）。
- **踏破ルート（実測）**:
  - lobby door **(1,105)** → 入 **(7,85)** [room1]
  - room1: trainer **(4,81)**、forward door **(1,79)**(step-on) → 入 **(7,46)** [room2]
  - room2: trainer **(4,42)**、forward door **(7,40)**(step-on) → 入 **(1,20)** [room3]
  - room3: trainer **(4,16)**、forward door **(7,14)**(step-on) → 入 **(1,7)** [Norman room]
  - Norman room: **Norman (4,2)**、(4,3) から Up+A で talk → 戦闘
- **door-cross primitive**: door は **step-on warp**（隣接タイルから warp 方向に 1 歩踏む
  と warp）。press-drop で 1 回目が落ちることがあるので **retry**。撃破後 trainer は
  その場に残り**物理 block**（NPC read は socket 競合で取りこぼすので drive script では
  観測済み trainer タイルを明示 block して BFS 迂回）。
- **nav は `map_data.get_cache().bfs_to_tile(8,1, start, {target}, blocked_tiles=...)`**
  で部屋内を BFS。歩行は step 毎に位置を検証して retry（drop 耐性）。

## Norman 戦 #1 の敗因（root cause）
1. **team が薄い**: 実戦力は Sceptile L48 単騎。他は L5〜17 で Norman 帯に無力。
2. **Rock Smash PP 枯渇**: gym 突入前に既に Rock Smash / Rock Tomb / Pursuit が 0 PP
   （道中で使い切っていた）。Leppa Berry で Rock Smash を 10PP 復活させたが、
   room3 + Norman で再び 0 に → best_move が弱い **Quick Attack(40, 等倍)**へ後退
   → Slaking を削り切れず被弾がかさむ。
3. **HP 持続不能**: Super Potion(50 回復)×2 では 4 体分を支えきれない。
   → Linoone/Slaking の前で Sceptile 気絶。

## in-battle 操作メカニクスの確立（重要・再利用可）
- **best_move 選択 = loop の実証済み API**:
  `battle_moves.best_move_index(c)`(0PP を skip・power×effectiveness 最大) +
  `battle_moves.move_select_sequence(slot)`(自己補正 B,B,Up,Up,Left,A,Up,Left,+nav,A)。
  **blind A 連打は cursor が RUN/POKEMON/BAG を confirm して技が commit されず enemy_hp
  不変になる**（今回の主要バグ）。必ず cursor reset 込みのこの sequence を使う。
- **Leppa Berry で PP 復活**（戦闘外）: Start→BAG→BERRIES(Right×2)→LEPPA→USE→Sceptile→
  ROCK SMASH。「PP was restored.」。※ `active_pp` は戦闘外だと gBattleMons が stale。
  実 PP は gPlayerParty[0] Attacks substruct(+8, key で復号)を読む。
- **in-battle Super Potion**: command menu(FIGHT)→Right→BAG→A。**bag は last-used
  pocket に開く**ので ITEMS へ Left cycle(BERRIES→TMs→POKéBALLS→ITEMS = Left×3)。
  Super Potion→A→USE→A→party→Sceptile→A。
- **switch/faint 画面(cb2 0x081B01B1)**: 気絶後の「Choose a POKéMON」は cursor が
  **気絶した先頭(slot0)に留まり A で選べず loop**する。party HP を読み **first-healthy
  slot へ Down してから A→A(SEND OUT)**。

## drive script のバグ（今回踏んだ・次回対策）
- **switch-YES trap**: 撃破後の「入れ替えますか？」に A 連打が YES を confirm →
  party-switch 画面で stuck。**advance は A でなく B**（B は text 送り + switch prompt で
  NO 選択、YES 誤確定しない）。
- **transient battle-end 誤検知**: `not in_battle` 1 フレームで戦闘終了判定すると
  animation 中の false-negative で誤終了。**overworld cb2 を 2 連続**で確認して終了。
- **self-bug 反省**: 使い捨て script で `time.sleep=0.5`(clobber)を数回書いた。
  必ず `time.sleep(0.5)`。長い script はファイルに書いて実行する。
